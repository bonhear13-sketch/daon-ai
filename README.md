1. **[Pages 설정 페이지 바로가기](https://github.com/bonhear13-sketch/daon-ai/settings/pages)** 접속

3. **Branch**: `main` 브랜치 / `/ (root)` 폴더 선택 후 **[Save]** 클릭
4. 약 1분 후 공식 웹사이트 주소로 24시간 언제든 접속 가능:
